# Pind Daan in Gaya Ji — Landing Site

React + Vite + Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build   # outputs to dist/
npm run preview # preview the production build locally
```

## Photography

`public/images/` holds real, licensed documentary photographs of Gaya Ji
(Vishnupad Temple, the Phalgu riverbed, Pind Daan rituals, Satvik food, and
local streets), sourced from Wikimedia Commons under CC BY-SA / CC0. See
`public/images/CREDITS.txt` for the attribution required by each photo's
license before reusing them elsewhere. The `PhotoFrame` component falls
back to a labeled placeholder if any image is ever removed.
